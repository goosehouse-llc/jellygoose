wall, brighter. Same jellygoose and floating screens as the live headers; the
background a made-up library of posters tilted away, with a film's timeline

pixels at 2x with a fixed height (the tilted wall makes WebKit think the page
is taller than it is). Not on App Store Connect yet: they go on the next
version, not 1.7.1.
