# JellyGoose 2.0.4 — App Store copy (all three platforms)

A small release on top of 2.0.3, build 111, prepared 2026-11-24 and not yet entered
on App Store Connect. It carries what was merged after 2.0.3 went out: on the Mac,
arrows to move rows and Home's banner with a mouse, and a library's filter buttons
wrapping instead of running off the window (issue #16); the banner's picture fading
in without a line where it starts; and album and playlist pages saying why their
songs couldn't be fetched, with Try Again, instead of looking empty.

The app's What's New card shows 2.0's on 2.0.4 (`WhatsNew.version` maps 2.0.4 to 2.0),
so someone coming straight from 1.8.1 still sees it, and no one sees it twice.

Promotional text, description, keywords, screenshots and review notes: 2.0.3's,
unchanged (App Store Connect carries all but the promotional text to a new version,
so that is copied from 2.0.3; What's New is set).

## iPhone and iPad — What's New

```
• Fixed: an album or playlist whose songs couldn't be fetched from the server looked empty; it now says why, with Try Again
• iPad: Home's banner picture now fades in smoothly, without a line where it begins
```

## Apple TV — What's New

```
• Fixed: an album or playlist whose songs couldn't be fetched from the server looked empty; it now says why, with Try Again
```

## Mac — What's New

```
• Rows on Home, title pages and elsewhere show arrows at either end while the pointer is over them, to move along with a mouse
• Home's banner shows arrows too, to go to the next or previous title
• A library's filter buttons now wrap onto a second line instead of running off the edge of the window
• Home's banner picture now fades in smoothly, without a line where it begins
• Fixed: an album or playlist whose songs couldn't be fetched from the server looked empty; it now says why, with Try Again
```
